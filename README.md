# Códigos Beecrowd em Linguagem C
___

Esse repositório foi criado na intenção de destacar minhas soluções em problemas de **lógica de programação** na plataforma Beecrowd.

Tive essa iniciativa de armazenar e passar a solucionar com frequência esse tipo de problema para intigar e enrriquecer minha mente diante de problemas computacionais.

___
# Estrutura do Repositório
___

Não penso em fazer nada complexo. Planejo dividir os códigos das soluções em pastas que referenciam as categorias nativas de problemas do próprio Beecrowd.

```
BEECROWD C/
├─── INICIANTE/
     ├─── iniciante_<código do problema>_<nome do problema>.c

     ├─── iniciante_<código do problema>_<nome do problema>.c

     ├─── strings_<código do problema>_<nome do problema>.c
```

___
# Cronograma do Repositório
___

Planejo resolver no mínimo 1 problema de cada categoria por semana para incentivar a constância. Meu objetivo com o repositório é aumentar a prática de programação lógica e me desafiar à novos problemas todos os dias.
